# AMO 관리자 Web

데모 서버에 연결하고 승인된 관리자 계정으로 로그인하면 **시나리오 검수** 메뉴가 표시됩니다. Taxi 성공·실패 시나리오에서 한 단계를 클릭하면 선행 단계가 필요한 경우 새 실행에서 먼저 준비한 뒤 선택한 단계를 재생합니다. 지도에는 해당 차량과 마지막으로 저장된 단계가 표시됩니다. 단계 상세에서 모의 결제, 적용 목적지, 요금·영수증, 복귀·충전 기록을 확인합니다.

**▶**로 표시된 단계는 서버가 현재 실행에서 허용한 선택지입니다. 실패·연결 복구 분기를 선택하면 같은 검수 실행에서 처리됩니다. **단계를 클릭해 기록만 보기**를 켜면 단계 선택이 기록 조회로 동작합니다.

**검수 이력**에서 이전 실행의 증거를 엽니다. **현재 검수 종료**는 재생을 끝내고 증거를 보관합니다. **검수 이력 초기화**는 삭제할 격리 기록의 건수를 확인하고 승인했을 때 실행합니다.

## Vision 판정 조회

**운영 개요 → Vision 판정**에서 차량, 판정 출처와 결과, 프레임 ID, 촬영·관제
수신 시각을 확인합니다. 이 표는 Admin(PyQt)과 같은 운영 조회의 최신 판정을
표시합니다. 관제에 기록된 판정이 없는 경우에는 빈 상태를 표시합니다.
